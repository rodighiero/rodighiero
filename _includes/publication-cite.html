{%- comment -%} Chicago author-date reference. The "Cite" button copies plain text from a hidden 
 (see scripts-site.js). Footer references use linked titles and italics.

Primary contributor is the author, or the editor(s) when there is no author
(publication_validator.rb requires one of the two).

The first name is inverted (Family, Given); the rest stay in normal order, with
a serial comma before "and". Formatting branches on the publication type.
{%- endcomment -%}
{%- assign _item = include.item -%}
{%- if _item.author -%}
  {%- assign _authors = _item.author | chicago_names: true -%}
  {%- assign _roleword = '' -%}
{%- elsif _item.editor -%}
  {%- assign _authors = _item.editor | chicago_names: true -%}
  {%- assign _people = _item.editor | split: ' and ' -%}
  {%- if _people.size > 1 -%}{%- assign _roleword = ', eds' -%}{%- else -%}{%- assign _roleword = ', ed' -%}{%- endif -%}
{%- endif -%}
{%- comment -%} The joins, the first name's inversion and the serial-comma rule are the
chicago_names filter (publication_credits.rb). {%- endcomment -%}
{%- assign _editors = _item.editor | chicago_names -%}
{%- assign _translators = _item.translator | chicago_names -%}
{%- assign _interviewers = _item.interviewer | chicago_names -%}
{%- assign _t = _item.type -%}
{%- comment -%} Without a `container` (publication_types.yml) the venue is the press and
stands in for a missing publisher; with one, it names what the work sits inside. Only the
reference grammar below knows type names, since Chicago's shapes are not in the
taxonomy. {%- endcomment -%}
{%- assign _container = site.data.publication_types[_t].container -%}
{%- if _container -%}{%- assign _pub = _item.publisher -%}{%- else -%}{%- assign _pub = _item.publisher | default: _item.venue -%}{%- endif -%}

{%- if _tlast == '?' or _tlast == '!' -%}{%- assign _dot = '' -%}{%- else -%}{%- assign _dot = '.' -%}{%- endif -%}

  {%- if _t == 'journal' or _t == 'magazine' or _t == 'chapter' or _t == 'conference' or _t == 'interview' -%}

  {%- endif -%}

{%- elsif _t == 'journal' or _t == 'magazine' %} “{{ _cite_title }}{{ _dot }}”{% if _item.translator %} Translated by {{ _translators }}.{% endif %} {{ _cite_venue }}{% if _item.volume %} {{ _item.volume }}{% endif %}{% if _item.issue %} ({{ _item.issue }}){% endif %}{% if _item.pages %}: {{ _item.pages }}{% endif %}.
