{%- comment -%} Formatted Chicago author-date reference for the "Cite" button, emitted as a hidden 
 and copied to the clipboard (see site-scripts.html). Plain text:
titles are not italicised — the reader can style them after pasting.

Primary contributor is the author, or the editor(s) when there is no author
(publication_validator.rb requires one of the two).

The first name is inverted (Family, Given); the rest stay in normal order, with
a serial comma before "and". Formatting branches on the publication type.
{%- endcomment -%}
{%- assign _item = include.item -%}
{%- if _item.author -%}
  {%- assign _people = _item.author | split: ' and ' -%}
  {%- assign _roleword = '' -%}
{%- elsif _item.editor -%}
  {%- assign _people = _item.editor | split: ' and ' -%}
  {%- if _people.size > 1 -%}{%- assign _roleword = ', eds' -%}{%- else -%}{%- assign _roleword = ', ed' -%}{%- endif -%}
{%- endif -%}
{%- comment -%} First contributor is inverted to Family, Given for Chicago style; the
rest join with a serial comma via credit-join.html. {%- endcomment -%}
{%- assign _first_p = _people | first | strip -%}
{%- assign _words = _first_p | split: ' ' -%}
{%- assign _family = _words | last -%}
{%- capture _given -%}{% for w in _words %}{% unless forloop.last %}{{ w }} {% endunless %}{% endfor %}{%- endcapture -%}
{%- assign _given = _given | strip -%}
{%- capture _first_formatted -%}{{ _family }}{%- if _given != '' -%}, {{ _given }}{%- endif -%}{%- endcapture -%}
{%- comment -%} Splitting on the absent "~~~" sentinel is Liquid's only way to wrap
one string in an array, so the inverted first
name can lead the list the rest joins onto. {%- endcomment -%}
{%- assign _rest_people = _people | slice: 1, 9999 -%}
{%- assign _display_people = _first_formatted | split: "~~~" | concat: _rest_people -%}
{%- capture _authors -%}{%- include credit-join.html items=_display_people serial_comma=true -%}{%- endcapture -%}
{%- comment -%} The secondary roles, each split and re-joined by credit-role.html. {%- endcomment -%}
{%- capture _editors -%}{%- include credit-role.html raw=_item.editor -%}{%- endcapture -%}
{%- capture _translators -%}{%- include credit-role.html raw=_item.translator -%}{%- endcapture -%}
{%- capture _interviewers -%}{%- include credit-role.html raw=_item.interviewer -%}{%- endcapture -%}
{%- assign _t = _item.type -%}
{%- comment -%} Without a `container` (publication_types.yml) the venue is the press and
stands in for a missing publisher; with one, it names what the work sits inside. Only the
reference grammar below knows type names, since Chicago's shapes are not in the
taxonomy. {%- endcomment -%}
{%- assign _container = site.data.publication_types[_t].container -%}
{%- if _container -%}{%- assign _pub = _item.publisher -%}{%- else -%}{%- assign _pub = _item.publisher | default: _item.venue -%}{%- endif -%}
{%- comment -%} Drop the title-final period when the title already ends in ? or !. {%- endcomment -%}
{%- assign _tlast = _item.title | slice: -1, 1 -%}
{%- if _tlast == '?' or _tlast == '!' -%}{%- assign _dot = '' -%}{%- else -%}{%- assign _dot = '.' -%}{%- endif -%}
{%- comment -%} Give the author block exactly one terminal period, even when a name already ends in one (e.g. an author string ending in "metaLAB."). {%- endcomment -%}
{%- assign _authblock = _authors | append: _roleword -%}
{%- assign _ablast = _authblock | slice: -1, 1 -%}
{%- unless _ablast == '.' -%}{%- assign _authblock = _authblock | append: '.' -%}{%- endunless -%}
{%- assign _doi_id = _item.doi | doi_id -%}

{%- elsif _t == 'journal' or _t == 'magazine' %} “{{ _item.title }}{{ _dot }}”{% if _item.translator %} Translated by {{ _translators }}.{% endif %} {{ _item.venue }}{% if _item.volume %} {{ _item.volume }}{% endif %}{% if _item.issue %} ({{ _item.issue }}){% endif %}{% if _item.pages %}: {{ _item.pages }}{% endif %}.

{%- elsif _t == 'interview' %} “{{ _item.title }}{{ _dot }}”{% if _item.interviewer %} Interview by {{ _interviewers }}.{% endif %}{% if _item.translator %} Translated by {{ _translators }}.{% endif %} {{ _item.venue }}.
