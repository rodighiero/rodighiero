How the Network Is Built

A Network of the Publications by Full-Text Similarity

  1. Each file in _publications/ is stripped to plain prose — no footnotes, headings, links, or markup.
  2. Its text becomes a 768-dimension vector via gte-base-en-v1.5; non-English originals are machine-translated first.
  3. Cosine similarity is measured between every pair of embedded papers.
    4. {%- comment -%} The numbers come from the build (network.json `params`), not typed. JSON turns 0.60 into 0.6, so two decimals are rebuilt by hand. {%- endcomment -%} {%- assign _p = site.data.network.params -%} {%- assign _strong = _p.strong_sim | times: 100 | round | prepend: '0.' -%} {%- assign _fallback = _p.fallback_sim | times: 100 | round | prepend: '0.' -%}
  4. Edges use mutual nearest neighbors (k = {{ _p.mutual_k }}): each ranks the other in its top {% if _p.mutual_k == 2 %}two{% else %}{{ _p.mutual_k }}{% endif %}, above {{ _strong }}.
  5. A node with no mutual match keeps one faint edge to its closest above {{ _fallback }}, or none.
  6. A translation stays a node, tied to its original by a dashed forced edge, not by similarity.
  7. A pre-computed D3 force simulation lays out the nodes, so the graph loads already settled.

Hover a node to read its title; click to select it and reveal its closest matches below.
